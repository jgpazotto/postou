Como usar o Postou — passo a passo

1️⃣ Comece pelos Usuários 👥

  1. Nome: o nome do usuário ou da marca (ex.: "Loja da Maria");
  2. Nicho: o assunto do perfil (moda, comida, estética...);
  3. Redes: adicione cada rede com o usuário sem o @ — o link é criado sozinho;
  4. Anotações: combinados, frequência de posts, o que a pessoa não gosta;
  5. Cor: escolha uma cor — ela identifica o cliente em todas as telas.

2️⃣ Planeje no Calendário 📅

  1. Clique no dia em que quer postar;
  2. Escolha o usuário e marque as redes onde o post vai sair;
  3. Dê um título curto (ex.: "Promoção de sexta");
  4. Defina data e hora e o tipo (foto, reel, story...);
  5. Cole a legenda pronta com hashtags — vai economizar tempo na hora de postar!

3️⃣ Acompanhe pelo Status 🗂

  • 💡 Ideia → ✏️ Rascunho → 🎬 Em produção → 👍 Aprovado → ⏰ Agendado → ✅ Publicado;
  • Use as setas ◀ ▶ para mover o post conforme ele avança;
  • Dica de ouro: só mova para Aprovado depois que o usuário disser SIM — evita retrabalho!

4️⃣ Use as Tarefas ✅

  • Anote tudo que precisa ser feito: gravar vídeo, criar arte, responder directs;
  • Sempre coloque um prazo — tarefas atrasadas ficam vermelhas;
  • Marque a caixinha quando terminar. Sensação boa garantida! 🎉

5️⃣ Guarde as Ideias 💡

  • Toda ideia boa vai para o banco: título, descrição e hashtags;
  • Quando chegar a hora, clique em "Virar postagem" — ela vai direto para o quadro de Status;
  • Use "Copiar texto" para levar legenda + hashtags para qualquer lugar.

🌅 Sua rotina diária com o Postou

  1. De manhã: abra a aba Hoje — ela mostra o que precisa sair e o que está atrasado;
  2. Use o botão 🚀 Postar: ele copia a legenda e abre a rede — é só colar e publicar;
  3. Marque ✅ Publicado! depois de postar;
  4. Fim do dia: planeje o dia seguinte no calendário;
  5. 1x por semana: clique em ⬇ Backup para guardar uma cópia dos seus dados.
Dúvidas? Clique no botão 💬 no cantinho da tela e pergunte ao assistente!
